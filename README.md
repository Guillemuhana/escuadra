# Escuadra Builders Group - React App

## Instalar
```bash
npm install
npm run dev
```

## Archivos importantes
- Logo: `src/assets/logo-escuadra.jpeg`
- Imagen principal: `src/assets/hero-escuadra.jpeg`
- Estilos: `src/styles.css`
- App completa: `src/App.jsx`

La burbuja del chatbot es demo. Después se puede conectar con Meta WhatsApp, n8n o cualquier agente externo.
